# Codex runtime

The Windows distribution of Needle includes the complete Codex CLI 0.144.0
Windows package as its managed worker runtime. The package contains Codex plus
the matching code-mode, command-runner, sandbox, and ripgrep resources required
for isolated repository exploration.

Source: https://github.com/openai/codex/tree/rust-v0.144.0
