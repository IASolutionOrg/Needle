# Code provenance

Needle is original greenfield source developed for this repository. No
third-party project source code has been imported into the workspace. The
packages remain `publish = false`; the source is offered under Apache-2.0.

The ripgrep benchmark fixtures describe the public ripgrep `14.1.1` snapshot at
commit `4649aa9700619f94cf9c66876e9549d83420e16c`. Each accepted report records
the exact fixture, model, and evidence boundary it uses.

The Codex pricing fixture is a dated transcription of the official rate card.
Its retrieval date, source URL, and content digest are stored with the fixture.
Calculated benchmark cost is not an independently verified provider invoice.

The Needle mark and banners under `assets/brand/` are original assets created
for this repository from an AI-assisted concept and rebuilt as deterministic
SVG. They contain no third-party marks, fonts, or embedded raster content.
